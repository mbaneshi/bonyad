نقشهٔ راه یک پروژهٔ گیت‌هاب است: **[نقشهٔ راه بنیاد (پروژهٔ ۲۴)](https://github.com/users/mbaneshi/projects/24)**.

کارها همان issueهای [مخزن](https://github.com/mbaneshi/bonyad/issues) هستند. هر issue
یک شاخهٔ کوتاه‌عمر و یک pull request به `dev` می‌شود؛ راهنمای مشارکت را در
[اینجا](/bonyad/contributing/) ببینید.

این سایت برد را بازتاب نمی‌دهد و فقط به آن پیوند می‌دهد؛ تا برد تنها منبع حقیقت
دربارهٔ برنامه و پیشرفت بماند.

نخستین نقطهٔ عطف «برش اول» است (نقطه، خط، سطح؛ مسیر انسان و عامل). ترتیب ساخت آن در
[طراحی پیش‌نویس](/bonyad/specs/first-slice-design/) آمده است.
