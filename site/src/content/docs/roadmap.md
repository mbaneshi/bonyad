The roadmap is a GitHub Project: **[Bonyad roadmap (Project 24)](https://github.com/users/mbaneshi/projects/24)**.

Work items are GitHub issues in the [repository](https://github.com/mbaneshi/bonyad/issues).
Each issue becomes one short-lived branch and one pull request into `dev`; see the
[contribution guide](/bonyad/contributing/).

This site does not mirror the board. It only links to it, so the board stays the
single source of truth for what is planned and what is done.

The first milestone is the *first slice* (point, line, surface; human and agent
paths). Its build sequence is in the [draft design](/bonyad/specs/first-slice-design/).
