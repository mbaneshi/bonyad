# Demo script (no API key)

`scenarios.json` is a scripted stand-in for the model: two scenarios, replayed turn by turn.
It ignores what you type; it exists so you can watch the agent path (streaming, tool progress,
the drawing updating) without a credential. `just agent-demo` starts the service with it.

Send any message once: the script creates A(0,0), B(4,0), C(0,3), a line A-B and a triangle, and
reports length 4 m and area 6 m². Send any second message: it moves the vertex to (8,0) and
reports 12 m². Restart the service to replay from the start.

It is generated by the same tool inputs the tests use; it is a demo, not evidence that a real
model behaves this way (that is `just agent-smoke`).
